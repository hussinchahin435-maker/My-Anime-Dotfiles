# Horimiya Terminal Theme 🌸

هذا الثيم مستوحى من ألوان الأنمي الدافئة **Horimiya**. صُمم ليضفي طابعاً هادئاً ومتناسقاً على بيئة العمل الخاصة بك.

## 📸 معاينة
![Horimiya Terminal](59533b1e97fcdcbb64ac5c5be00024df.jpg)

## 🎨 لوحة الألوان
تم اختيار هذه الألوان بعناية لتكون مريحة للعين ومتكاملة:

| المسمى | الكود |
| :--- | :--- |
| **Foreground** | `#f4eade` |
| **Background** | `#1a1615` |
| **Color 1 (Red)** | `#d9644d` |
| **Color 2 (Green)** | `#4a6b52` |
| **Color 3 (Yellow)** | `#f0cb42` |
| **Color 4 (Deep Blue)** | `#1d3557` |
| **Color 5 (Brown)** | `#b86a3d` |
| **Color 6 (Light Blue)** | `#457b9d` |
| **Color 7 (Orange)** | `#e3a87c` |
| **Color 8 (Olive)** | `#2b332d` |

## 🚀 طريقة التثبيت
لإضافة هذه الألوان إلى الـ `fish shell` الخاص بك، أضف هذا السطر إلى `~/.config/fish/config.fish`:

```fish
set -g fish_color_normal f4eade; set -g fish_color_command e3a87c; set -g fish_color_param 4a6b52; set -g fish_color_error d9644d; set -g fish_color_autosuggestion 457b9d
